## Smoke Test

Smoke-tested on 2026-10-01 using Python 3.11.9, CPU PyTorch 2.14.0, Ultralytics 8.4.170 in a temporary test environment, Open Image Models 0.6.0, Fast Plate OCR 1.1.0, FastALPR 0.4.0, and ONNX Runtime 1.30.0.

- `yolov8n.pt` loaded and ran on the workspace traffic photo (`evidence1.png`): 6 boxes, including person, motorcycle, truck, and car.
- `helmet-best.pt` loaded and ran on the same photo: 2 boxes, both `With Helmet` at confidence 0.300 and 0.279. This is an inference smoke test, not an accuracy assessment.
- FastALPR loaded the plate detector and OCR ONNX model using `CPUExecutionProvider`. On FastALPR's upstream test image it detected one plate at confidence 0.843 and read `5AU5341`. On `evidence1.png` it detected one plate at confidence 0.869 and read `B09922`.
- ONNX Runtime reported `AzureExecutionProvider` and `CPUExecutionProvider`; CPU was explicitly selected for the test.

The machine has an NVIDIA RTX 4050, but the installed PyTorch is CPU-only (`2.14.0+cpu`), and no CUDA ONNX provider is installed. GPU inference was not tested. The system's pre-existing Ultralytics 8.1.29 could not load these checkpoints with the installed PyTorch safe-loading default; the smoke test succeeded with Ultralytics 8.4.170 installed only in the temporary test environment. No global Python packages were upgraded.

The smoke-test image and Python environment are not model artifacts. This test does not validate video tracking, speed calibration, traffic-light state, lane regions, or any incident rules.
